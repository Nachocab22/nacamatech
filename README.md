# Nacamatech · Dailymalist privacy

Static, bilingual privacy policy. No JavaScript, external fonts, analytics, or build dependencies.

## Deploy with Vercel

Import this repository, choose project name `nacamatech` (subject to availability), and deploy. Framework: Other. Build command: leave blank. Output directory: `.` (configured in `vercel.json`).

Spanish policy: `/`
English policy: `/en/`

Use the production URLs in App Store Connect and link the policy inside the app.

## Preview locally

Run `python3 -m http.server 4173 ` and open http://localhost:4173.

## Update

Edit `index.html` and `en.html`. Review both policies when the app’s data practices change, including future CloudKit integration.
